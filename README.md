# Railway-DBMS-Core
A normalized (3NF) Relational Database System for Railway Reservations featuring transaction logic and data integrity.

## 🏫 Project Context
This system was developed as a **Minor Project** for the **Database Management Systems (DBMS)** course during my B.Tech in Computer Science Engineering at **DIT University**. 

The goal was to design a scalable backend for a transportation network that maintains strict data integrity and handles concurrent booking requests.
